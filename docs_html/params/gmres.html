7.2. gmres

Declared in src_gmres/gmres_namespace.H; defaults set in InitializeGmresNamespace() (src_gmres/gmres_functions.cpp).

Parameter

Type

Default

Description

precon_type

int

1

preconditioner type 1 = projection preconditioner -1 = projection preconditioner with expensive pressure update 2 = lower triangular preconditioner -2 = lower triangular preconditioner with negative sign 3 = upper triangular preconditioner -3 = upper triangular preconditioner with negative sign 4 = Block diagonal preconditioner -4 = Block diagonal preconditioner with negative sign

visc_schur_approx

int

0

use the viscosity-based BFBt Schur complement (from Georg Stadler)

p_norm_weight

Real

1.

weighting of pressure when computing norms and inner products

scale_factor

Real

1.

scale theta_alpha, beta, gamma, and b_u by this, and then scale x_p by the inverse

mg_verbose

int

0

multigrid verbosity

cg_verbose

int

0

BiCGStab (mg_bottom_solver=1) verbosity

mg_max_vcycles

int

1

maximum number of V-cycles

mg_minwidth

int

2

length of box at coarsest multigrid level

mg_bottom_solver

int

0

bottom solver type

mg_nsmooths_down

int

2

number of smooths at each level on the way down

mg_nsmooths_up

int

2

number of smooths at each level on the way up

mg_nsmooths_bottom

int

8

number of smooths at the bottom (only if mg_bottom_solver=0)

mg_max_bottom_nlevels

int

10

for mg_bottom_solver 4, number of additional levels of multigrid

mg_rel_tol

Real

1.e-9

rel_tol for Poisson solve

mg_abs_tol

Real

1.e-14

abs_tol for Poisson solve

stag_mg_verbosity

int

0

verbosity

stag_mg_max_vcycles

int

1

max number of v-cycles

stag_mg_minwidth

int

2

length of box at coarsest multigrid level

stag_mg_bottom_solver

int

0

bottom solver type

stag_mg_nsmooths_down

int

2

number of smooths at each level on the way down

stag_mg_nsmooths_up

int

2

number of smooths at each level on the way up

stag_mg_nsmooths_bottom

int

8

number of smooths at the bottom

stag_mg_max_bottom_nlevels

int

10

for stag_mg_bottom_solver 4, number of additional levels of multigrid

stag_mg_omega

Real

1.

weighted-jacobi omega coefficient

stag_mg_smoother

int

1

0 = jacobi; 1 = 2*dm-color Gauss-Seidel

stag_mg_rel_tol

Real

1.e-9

relative tolerance stopping criteria

gmres_rel_tol

Real

1.e-9

relative tolerance stopping criteria

gmres_abs_tol

Real

0.

absolute tolerance stopping criteria

gmres_verbose

int

1

gmres verbosity; if greater than 1, more residuals will be printed out

gmres_max_outer

int

20

max number of outer iterations

gmres_max_inner

int

5

max number of inner iterations, or restart number

gmres_max_iter

int

100

max number of gmres iterations

gmres_min_iter

int

1

min number of gmres iterations

gmres_spatial_order

int

2

spatial order of viscous and gradient operators in matrix “A”
